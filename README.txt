ALMANCA PORTALI - GITHUB PAGES PAKETI

Yukleme:
1. ZIP dosyasini bilgisayarinizda acin.
2. Icinden cikan tum dosyalari GitHub deponuzun ana dizinine yukleyin.
3. GitHub > Settings > Pages bolumunde Branch: main, Folder: /root secin.
4. Ana ekran uygulamasinin eski surumunu iPhone'dan silin.
5. GitHub Pages adresini yeniden acip Ana Ekrana Ekle secenegini kullanin.

Onemli:
- index.html dosyasinin adi degistirilmemelidir.
- manifest.webmanifest, sw.js ve ikonlar index.html ile ayni klasorde kalmalidir.
