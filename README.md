# Almanca Öğrenme Portalı

GitHub Pages üzerinde çalışacak statik pakettir.

## Yayınlama
1. Bu paketin içeriğini GitHub deposunun kök dizinine yükleyin.
2. GitHub > Settings > Pages bölümünde `Deploy from a branch` seçin.
3. Branch olarak `main`, klasör olarak `/root` seçip kaydedin.

## Mobil yapı
- Sol üst hamburger menü
- Seçimden sonra otomatik kapanan çekmece
- Ayrı tam ekran Oku, Odak ve Test akışları
- Ana okuma ekranında Fragen alanı gizli
- Uzun basmada Dinle, Çeviri, kelime ve seçim işlemleri
- Dokunmatik kaydırmayla metin seçiminin çakışmasını azaltan salt okunur davranış
- Paragraf görünümünde ekrana oturan dikey sayfalama

Masaüstü düzeni ve özellikleri korunmuştur. Mobil katman yalnızca 900 px ve altındaki ekranlarda etkinleşir.
