# Almanca Öğrenme Portalı v9 Mobile

Bu klasör GitHub Pages için hazırdır.

## Yayınlama
1. Bu klasördeki tüm dosyaları GitHub deposunun kök dizinine yükleyin.
2. GitHub deposunda **Settings > Pages** bölümünü açın.
3. **Deploy from a branch** seçeneğini seçin.
4. Branch olarak `main`, klasör olarak `/ (root)` seçin ve kaydedin.

## Dosyalar
- `index.html`: Portalın güncel sürümü
- `manifest.webmanifest`: PWA yapılandırması
- `sw.js`: Çevrimdışı uygulama kabuğu ve önbellek
- `icon-*.png`: Telefon, tablet ve PWA ikonları

Not: Çalışma JSON dosyaları kullanıcı tarafından portal içinden yüklenir. Son yüklenen geçerli JSON içerikleri mobil cihazın tarayıcı depolamasında saklanır.
